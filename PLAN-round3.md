## 0. Goal, restated

(1) A group heading is never a pick-one choice: compile, the 1/N refusal, loadout resolution and the outline all count OPTIONS only; every non-comment-only group heading gets an ordinary checkbox; Nemo's "first member heads the group" trick is replaced by a synthesized comment-only default heading, and existing Nemo documents upgrade on load. (2) One button turns the multi-selection into a group through the existing atomic `createGroup`, hardened with clear refusals. (3) ST files with unusable `prompt_order` entries (Sola V3's `character_id: "undefined"`) import with a note instead of a 400; refuse only when nothing usable remains. (4) A `sola3` recognizer for Sola V3's `══` sections and `[PICK 1: …]` tags. (5) README + version 2.2.0.

Out of scope (owner, roadmap 016): linked pick-one across positions (GROUNDING stays two toggles + note), nested headings, explicit heading members, the four selection rules, migrating the owner's live library (the session deploys; the builder never touches `:8001`).

## 4. What could go wrong, ranked (earliest visibility)
1. **Upgrade mis-scoped**: a Nemo sub-header-headed pick-one group (text-bearing `@section-header` header) must NOT be converted; a former-option header is detected only by its `@mutual-exclusive-group` tag. If some owner-edited Nemo doc has a header whose content lost the tag (ST panel edit), it stays as is — the heading simply becomes a checkbox. Visible in chunk 2's unit tests; the dev library's real Nemo 11.5.2 import (check-nemo-delete n2 count 44) is the integration canary.
2. **Group key change on upgrade** (`grp:<old header key>` → `grp:<new key>`): any client holding a key across a boot gets a 404 then refreshes; `collapsed` sets are per view and transient. Visible in n1.
3. **Bridge re-apply after upgrade**: the compile hash changes once per upgraded Nemo doc; if the slot binds one, the bridge applies at boot. Visible in n1 `converged()`.
4. **createGroup refusals vs. existing callers**: the MCP `preset_op` exposes createGroup; a script relying on the silent reorder of non-adjacent keys breaks by design. Visible in chunk 4 tests.
5. **ST popup API** (`POPUP_TYPE.CONFIRM` + custom `okButton`, result constant) — [INFERENCE] from ST's `popup.js`; builder reads it in the dev container's `public/scripts/popup.js` before chunk 4 UI.
6. **Sola V3 real-file drift**: names carry trailing spaces and emoji; regexes anchor on `[PICK 1:` and `═{3,}` only. Visible in `sola3.test.js` on the real fixture.
7. **Graceful import over-cleaning**: dropping a prompt with a non-string identifier also removes it from `byid`, so order entries referencing it become ghosts (existing ghost path). Visible in `graceful-import.test.js`.
8. **Known flakes**: `check-fix1` f10 and `check-nemo-delete` n4 timeout — report, don't chase.
9. **Live library** (session, not builder): the owner's Nemo documents upgrade in memory at the next plugin start; the first save writes the `before upgrade` revision; back up `st/data/default-user/preset-manager/` first, as every deploy does.
